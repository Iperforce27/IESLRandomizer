
# IESL Randomizer (by Iper)

Have you ever dreamt of being able to randomly generate a team with your favourite IESL players? Now you can! Just choose the formation and start gambling!

## How to use

1. Go to the [releases](https://github.com/Iperforce27/IESLRandomizer/releases) tab and download the most recent one
2. Unpack the zip file
3. Run the exe
4. Input the number of players for each role, choose whether you want to randomize the staff (coach and manager)
5. Click "Randomize!"

>Note: the IESL.xlsx and Images.zip files must be in the same folder of the .exe file for it to work, do NOT unpack the Images.zip file
